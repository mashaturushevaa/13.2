# Практична робота 13.2: Real-time Healthcare Stream Processing

**Виконала:** Марія Турушева  
**Тема:** Complex Event Processing (CEP) та медична IoT-аналітика

## 1. Опис проекту
Реалізовано систему моніторингу стану пацієнта в реальному часі. Система аналізує потоки даних (пульс, кисень, температура) та використовує CEP-паттерни для виявлення критичних станів.

## 2. Складні події (Complex Events)
Головною особливістю системи є виявлення кореляції між різними показниками:
- **Подія "Гіпоксія + Тахікардія":** Спрацьовує лише при одночасному підвищенні пульсу (>120) та зниженні кисню (<90).
- **Пріоритезація:** Система автоматично призначає пріоритет тривоги (Low/Medium/High) залежно від ступеня відхилення показників.

## 3. Технічна реалізація
- **Stream Sources:** Віртуальні Items, що генерують дані з інтервалом в 1 хвилину.
- **Processing Logic:** Rules DSL реалізує логіку "вікна подій" та часову кореляцію.
- **Visualization:** Медичний дашборд із кольоровою кодуванням станів (Зелений/Помаранчевий/Червоний).

## 4. Результати
Система забезпечує низьку затримку (latency) при обробці подій та дозволяє автоматизувати роботу медичного персоналу завдяки чіткій пріоритезації критичних станів.
